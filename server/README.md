# IBM Full Stack Developer Capstone

A dealership application built as part of the IBM Full Stack Developer Capstone project.

## Technologies

- Python and Django
- JavaScript, React, and Node.js
- Database integration
- REST API endpoints

## Project Structure

- `djangoapp/` — Django application, models, views, and API routes
- `djangoproj/` — Django project configuration
- `database/` — Node.js backend and database-related code
- `frontend/` — React frontend and static pages
- `evidence/` — Lab command outputs and assessment evidence

## Run the Django Server

Activate your Python virtual environment, move into the `server` directory, and run:

```bash
python manage.py runserver 0.0.0.0:8000
```

Use the port configured for your lab environment if it differs.

## Security

Keep environment files, API tokens, passwords, and other credentials out of version control.
