# Dealership Website — Full Stack Capstone Project

## Repository Name
xrwvm-fullstack_developer_capstone

## Project Name
Dealership Website — Full Stack Capstone Project

## Project Description
A full-stack dealership application built with Django, React, Node.js, and a database. The application allows users to browse dealerships, view dealer details, log in, and post dealership reviews.

## Technologies
- Python and Django
- React
- Node.js and Express
- Database integration
- Docker and Kubernetes
- GitHub Actions

## Features
- View dealership listings
- Filter dealerships by state
- View dealer details and customer reviews
- User authentication
- Submit dealership reviews
- Analyze review sentiment
